# block textures

drop 16x16 PNGs here to override the procedural textures. any that are missing fall back
to the generated pixel-art. bigger images are nearest-downsampled to 16x16.

filenames (one per block face group):

    stone.png  dirt.png  grass_top.png  grass_side.png  sand.png
    wood_side.png  wood_top.png  leaves.png  glow.png

nothing is bundled — the engine only loads what you put here. use your own art or a
resource pack you own; don't commit copyrighted texture files to the repo.
