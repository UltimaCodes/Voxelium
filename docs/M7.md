# M7 — indirect rendering + gpu culling

date: 2026-07-21
draw calls for the whole world: **1**. that was the deliverable.

## what got added

- `render/Renderer`: one persistent-mapped quad arena (32 MB, 4M quads,
  MAP_PERSISTENT|COHERENT, mapped once at init). chunk upload = memcpy into the map.
- free-list sub-allocator: first-fit, adjacent blocks merge on recycle. freed ranges
  recycle through a 3-frame fence ring — a range is reusable only after the GPU
  provably finished every frame that might still read it (GL fences are ordered, so a
  late fence covers earlier work too).
- lazy defrag: if an alloc ever fails, hardReset (glFinish + allocator reset) and the
  manager re-uploads every live chunk from its CPU-side quad copies. rare by
  construction — the arena is ~6x the radius-16 working set — and logged loudly.
- `cull.comp`: one invocation per loaded chunk. AABB vs 5 frustum planes (infinite
  reversed-z has no far plane), visible chunks atomicAdd a slot and write their draw
  command + camera-relative offset. chunk positions stored in chunk units as ints so
  the offset math is exact at any distance from origin.
- `glMultiDrawArraysIndirectCount` (core 4.6): the gpu-written count feeds the draw
  through GL_PARAMETER_BUFFER — the visible count never touches the CPU. the HUD reads
  it through a 3-slot readback ring with ~3 frames of latency, no stalls.
- the MDI trick that makes vertex pulling work globally: each command's `first` is
  quadIndex*6, and gl_VertexID starts at `first` per sub-draw, so gl_VertexID/6 indexes
  the arena directly. per-draw chunk offsets come from an SSBO indexed by gl_DrawID.
- chunk metadata rebuilt only when the chunk set changes (load/unload), not per frame.
  steady-state per-frame CPU: uniforms + one dispatch + one draw. zero per-chunk work.

## numbers

| metric | M5/M6 (per-chunk draws) | M7 |
|---|---|---|
| draw calls | 349 | **1** |
| gpu culled chunks | 349 (cpu frustum) | **349 (compute)** — exact match |
| smoke coverage | 773,776 px | **773,776 px** — byte-identical |
| arena | n/a (per-chunk SSBOs) | 2.2 / 32 MB used, healthy free list |
| stress re-stream worst update | 0.96 ms | 0.94 ms |

the cpu-vs-gpu cull match and byte-identical image are the correctness proof: same
planes, same AABB math, same pixels — only the machinery moved to the GPU.

M8 (cave culling) plugs into cull.comp: connectivity flood-fill writes a visibility set,
the compute pass tests membership alongside the frustum. the readback ring is already
there to measure chunks-drawn before/after underground.
