# M10 — terrain + interaction

date: 2026-07-21
new dep: FastNoise2 v1.1.1 (SIMD noise — the last one on the approved list in use)

## terrain (gen/TerrainGenerator)

- heights: domain-warped fractal simplex (4 octaves, warp amplitude 28) on top of a
  base height from very-low-frequency continentalness noise through a piecewise-linear
  spline (52..108). that spline is the "biome" control for now: plains, hills,
  mountains blend continuously.
- caves: cheese blobs (3d fbm > 0.56) + noodle tunnels (ridged > 0.90), only carving
  4 <= y <= surface-4 so the crust and floor stay intact. glow deposits spawn on cave
  floors via a deterministic voxel hash (~1 per 512 floor cells) — caves are actually
  lit when you find them.
- fully deterministic from the seed, chunk-independent: every value is a pure function
  of world coords. one generator instance serves all workers (node trees immutable).
- the M9 glow room is kept as the lighting regression anchor, now with a re-solidified
  1-block shell so no cave can crack it open.
- gen avg 1.42 ms/chunk on workers (noise-bound). world is cavey: 3.16M quads resident
  (24 MB of the now-64 MB arena), only 458 of 2116 chunks uniform.

## interaction

- raycast: Amanatides & Woo DDA (world/Raycast.hpp), 6 block reach.
- LMB breaks, MMB places (1/2/3 select stone/dirt/glow), only while the cursor is
  captured so UI clicks can't punch holes in the world.
- setBlock is the spec's edit fast path: spin the (sub-millisecond) in-flight job refs
  out, write the voxel, settle the light BFS synchronously, then remesh the chunk +
  border neighbors + light-touched chunks on the main thread with the manager's own
  mesher. edit to visible in the same frame. stale worker results get dropped by the
  state guard.

## player (world/Player)

- fixed 60 Hz timestep accumulator — framerate cannot change physics, extending the
  "fps never changes game speed" rule. AABB 0.6 x 1.8, swept axis-by-axis (y first),
  gravity 32, jump 9, walk 4.4. F5 toggles walk/fly; walk captures the mouse.
