# M5 — world of chunks

date: 2026-07-21
new dep: ankerl::unordered_dense v4.8.1 (world map — the last one from the approved list
besides stb_image and FastNoise2)

## what got added

- palette-compressed `Chunk`: uniform chunks (all air / all stone) store one id and no
  index array. otherwise indices are bit-packed at ceil(log2(palette)) bits, growing a
  bit at a time with a repack. straddled packing — index i at bit i*bits, spans two
  words when it must; a multiply and two shifts, no division, no per-width magic.
  stale palette entries aren't GC'd until M12's save repack, documented in the header.
- `ChunkManager`: unordered_dense map keyed by ChunkPos (wyhash over the 12 raw bytes),
  chunk objects from a slab `Pool` (released chunks keep their buffer capacity, so
  steady-state load/unload allocates nothing). load/unload by distance with +1 ring of
  hysteresis. gen and mesh run under per-frame budgets (24/16) so a load burst costs a
  few longer frames, not one stall — real fix is M6 workers.
- chunks mesh only when all 6 neighbors have voxel data (data ring = render radius + 1),
  feeding real neighbor pads into the greedy mesher — chunk seams cull correctly the
  first time, nothing ever gets remeshed because a neighbor showed up late.
- world height fixed at 4 chunks for now (sky light in M9 wants a defined top).
- CPU frustum culling: Gribb/Hartmann planes from the view-proj, positive-vertex AABB
  test. only 5 planes — the infinite reversed-z projection has no far plane.
- camera-relative rendering: camera position is a dvec3, the view matrix sits at the
  origin, chunks get a float offset uniform. world coords never touch the GPU, so
  precision doesn't rot with distance from origin.
- gen placeholder in gen/TestTerrain: deterministic worldspace sine surface, fully
  chunk-independent. FastNoise2 replaces the guts in M10.
- terrain "dark speck" check: sampled wedge pixels are exactly grass x 0.8 side shade —
  step risers at grazing angles, real geometry, not cracks. chunk borders watertight.

## known temporary sins

- one draw call per visible chunk (349 of them). the spec's "never one draw per chunk"
  rule is the M7 deliverable — persistent arena + glMultiDrawArraysIndirect + gpu
  culling collapse this to 1. per-chunk SSBO churn on load/unload goes away then too.
- mesh time regressed a hair vs the flat-array M4 (0.039-0.052 vs 0.057 — actually still
  faster on real terrain thanks to uniform fast paths; the palette get() cost shows in
  the oracle chunk: naive 0.35 ms vs 0.20 before). fine — meshing reads through get()
  by design so storage stays swappable; if it ever matters, the mesher can decode
  palette indices column-wise instead.
