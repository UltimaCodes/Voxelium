# M2 — debug infrastructure

date: 2026-07-20
new deps: GLM 1.0.1, Dear ImGui 1.92.8 (pinned in cmake/Dependencies.cmake)

## what got added

- imgui debug HUD (F3): frame graph (240 samples), frame/gpu ms + fps, heap allocs/frame,
  draw call + tri counters, camera state, scrolling log view. debug tooling only, gameplay
  UI will never be imgui.
- log rewrite: same VX_INFO/VX_ERROR front end, now writes to stderr + a fixed 256-line
  ring the HUD reads. ring entries are fixed char arrays — logging never allocates.
- gl debug callback now goes through the logger, so driver messages show up in the HUD.
- heap alloc counter: global operator new/delete replacements counting into atomics, HUD
  shows the per-frame delta. imgui allocates via malloc so it doesn't pollute the count —
  the number is engine code only. target once the real render loop exists: exactly 0.
  it already reads 0 with the triangle scene.
- gpu timer: GL_TIME_ELAPSED queries in a 4-frame ring, results read only when available,
  never a stall. this is what will prove per-effect costs in M11.
- freefly camera: hold RMB to fly, wasd + space/ctrl, shift = 8x, scroll = base speed.
  mouse capture with raw motion. imgui gets input priority (WantCaptureMouse/Keyboard).
- reversed-z depth, adopted now instead of retrofitted later: glClipControl 0..1 clip,
  clear depth 0, GL_GREATER, infinite-far projection (render/Camera.hpp has the matrix
  derivation). at 32 chunks of view distance a standard depth buffer z-fights; this
  concentrates float precision where it's needed and there's no far plane to tune.
- scroll callback chains through imgui's (Window::hookScroll) so both see the wheel.

## numbers

- smoke (now renders scene + HUD offscreen): 162,672 / 921,600 px covered (17.7%) at
  1280x720, byte-identical between Debug and Release builds — fully deterministic.
- heap allocs/frame: 0 in the steady-state loop (verified in HUD).
- both configs warning-clean, -Wall -Wextra -Wpedantic -Werror, gcc 16.1.
- windowed run is vsync-bound as expected; gpu time for the triangle is ~0.01 ms.
- expected noise: nvidia perf note about pixel transfer sync during smoke readback
  (glReadPixels is a sync point by design, smoke path only).
